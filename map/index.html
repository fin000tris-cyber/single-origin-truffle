你現在，走到哪裡了？先選你的階段，再找你的狀態
這個階段，任務只有一個：先讓身體被接住、先有感。
下面選一個最像你的狀態，我給你一條專屬路線。
↑ 點一個狀態，路線就出來了。

給熬夜的你：先安神養腎，再回頭顧肝

1
起點，三部一起：「自律神經失衡」+ 腎臟兩部曲（腎・啟動修復 → 腎・排毒再生，兩部要連貫聽，不能拆開）Premium。
2
接著補鐵：「活化鐵蛋白」Premium，用聽的鐵質補充。
3
然後才是：肝臟三部曲（重度爆肝 → 肝腎排毒加強 → 肝臟清淤養血）一般冥想。
聽到有感之後 → 正式課：學會「八個細胞物質還原」，從被接住，變成自己會。

給輪班的你：身體跟著班表亂，先穩住

1
第一步：「自律神經失衡」Premium，作息亂掉的開關，先在這裡調。
2
接著：「血液活化」一般冥想。
3
然後：「血管活化」+「血氧提升」一般冥想，把三部曲走完。
4
延伸第四步：再加入「心臟保養」一般冥想。
穩下來之後 → 正式課：把工具學回家，以後換什麼班，都有辦法照顧自己。

給扛著很多的你：先讓神經鬆一格

1
起點：「自律神經失衡」Premium，長期緊繃的人，從這裡開始最有感。
2
接著：腎臟兩部曲（腎・啟動修復 → 腎・排毒再生，連貫聽，不拆開）Premium。
3
日常底：血液三部曲+肝臟三部曲 一般冥想。
但你心裡知道，有些重量不是身體的 → 正式課的靈魂能量釋放，才是放下它們的地方。

給累到不行的你：什麼都別想，躺著聽就好

1
先聽：「血液活化」一般冥想，躺著聽就好，聽完就睡。
2
接著：腎臟兩部曲（腎・啟動修復 → 腎・排毒再生，連貫聽，不拆開）Premium。
3
再聽：「自律神經失衡」Premium。一天一部就好，不用趕——我們走得緩慢，但非常有效率。
等你緩過來 → 正式課在等你。不急，它一直都在。

給常便祕的你：先把腸道的卡，鬆開

2
想更完整：搭配血液三部曲（血液活化 → 血管活化 → 血氧提升）一般冥想，讓循環一起帶動。
想從根源處理 → 正式課：把身體的卡，和情緒的卡，一起鬆開。

給月經不太順的你：先把血養起來

2
接著補鐵：「活化鐵蛋白」Premium，用聽的鐵質補充，把氣色養回來。
想走更深 → 正式課：把身體與情緒的重量，一起卸下來。

給想找回精氣神的你：從血路開始亮起來

2

想走更遠 → 正式課的「八個細胞物質還原」，是把保養變成日常功夫的那一步。

新朋友，歡迎！從最基礎的開始

1
第一步：「血液活化」一般冥想——感受一次「聽完之後，身體的差別」，這是最容易有感的入口。

哪天你想要的不只是「聽」，而是「自己會」 → 正式課，我帶你。

已經在 Premium 的你：先把這條線用好

1
先體驗：腎・啟動修復、腎・排毒再生、自律神經失衡、活化鐵蛋白 Premium——這條線修的是「身體」。

3
那不是身體的累。那是情緒和靈魂的重量——這條路，在正式課裡。
訂閱，是我每個月陪你一次；課程，是你從此自己就會了。訂閱會到期，學進身體的東西，沒人拿得走。
恭喜你，你已經拿到整張地圖了。前三堂，是全系統最重要的精華。
正式課・前四堂

八個細胞物質還原：解說 → 介紹 → 實作 → 演練

這不是「課程內容」，這是你要帶走一輩子的日常工具。每天幾分鐘，自己保養自己。

請把它當成這個階段唯一的重點，學到會為止。

報喜機制

身體開始轉變了？貼上「報喜✨」說出來！

睡得比較沉、肩膀鬆一塊、早上人是亮的——再小都算，都值得報喜。

用「報喜✨」標籤分享，每三次解鎖一部冥想影片。那些影片不是用錢買的，是你的身體親自幫你賺回來的。每一部，都是一張獎狀。

別再默默變好了。變好這件事，值得被說出來，也值得被獎勵。

再走一輪

修復是上半場，開創是下半場。準備好開創了？先走進「談錢篇」——再把長出來的可能，用「Premium報喜✨」說給我們聽。
